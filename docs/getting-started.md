# Getting started

This guide runs Goldilocks on your own computer. To try it first, the website
[workbench.goldilocks.ac.uk](https://workbench.goldilocks.ac.uk) needs no
installation, but it can't use Claude, OpenAI or Gemini, doesn't search
Materials Project and has no MLIP Playground.
